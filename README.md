# Herong Bai

Bilingual personal website for pianist Herong Bai: https://herongbai.com/.

## Pages

- Home: Brahms, Concerto, Etudes third, followed by Beethoven / Bach / Chopin in a responsive recording grid.
- Music: recordings, recitals, festivals and recognition.
- Community: Tongxinyuan teaching, Back to BACH, and other educational programmes.
- Research: mathematics and music, aviation data analysis, and economics.
- About: biography, CV, press and timeline.
- Contact: professional email and Instagram.

The site uses static HTML, CSS and JavaScript, with self-hosted open-source fonts. English is the default language; the language choice persists across pages.

## Media

recordings.json contains the six recordings and their original-quality GitHub Release URLs. Original video files are not re-encoded. Earlier release attachments remain available.

The player requests a recording only after selection and includes native controls, inline playback, retry and direct-link fallbacks. Network access to GitHub-hosted video depends on the visitor’s connection.

Press entries distinguish individual profiles, event reporting, institutional videos and reprints. Project pages describe research contributions separately from publication authorship. Only public project accounts and approved media belong in this repository.

Private source documents, working notes, raw research data, local review files and video originals are excluded from the Pages source. Keep CNAME, deployment settings and existing media when updating the website.
